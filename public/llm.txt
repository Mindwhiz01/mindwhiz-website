## Content Model

All content is authored as typed data in `src/lib/`:

### Files

1. **content.ts** - Home page, navigation, footer, stats, testimonials, case studies
2. **servicePages.ts** - 9 service detail pages
3. **industryPages.ts** - 9 industry pages
4. **locations.ts** - 3 location pages (US, UK, Pakistan)
5. **blog.ts** - Blog articles and metadata
6. **caseStudies.ts** - Case study data
7. **seo.config.ts** - SEO metadata map for all pages

### Content Approach

- No CMS or database - all content is hardcoded in TypeScript
- Shared content renderers pick up data from typed modules
- Changes require code updates and deployment
- Content is version-controlled via git

## Security Implementation

### Content Security Policy (CSP)

- **Status:** Report-Only mode (CSP-Report-Only header)
- **Plan:** Upgrade to enforcement after LeadConnector verification
- **Allowed Sources:**
  - Self (same-origin)
  - LeadConnector (link.msgsndr.com, leadconnectorhq.com)
  - Google Tag Manager (www.googletagmanager.com)
  - Meta Pixel (connect.facebook.net, facebook.com)
  - Unsplash (images.unsplash.com) for marketing imagery
  - Inline scripts for React hydration and framer-motion

### Security Headers

- **X-Content-Type-Options:** nosniff
- **X-Frame-Options:** DENY (prevent clickjacking)
- **Referrer-Policy:** strict-origin-when-cross-origin
- **Strict-Transport-Security:** max-age=63072000 (2 years)
- **Permissions-Policy:** Blocks camera, microphone, geolocation, browsing-topics

### Third-Party Integrations

- **LeadConnector:** Embedded forms for contact, careers, booking
- **Google Analytics:** Via Google Tag Manager
